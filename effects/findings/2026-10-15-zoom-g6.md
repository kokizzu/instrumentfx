# Zoom G6

Reviewed **2026-10-15**. Guitar multi-effects; **large**, built-in expression. Specifications below come from Zoom's product, operation manual and effect list, not the Shopee description. Partial: exact current library subtotals and current market ranges remain unresolved.

## Required comparison

| Field | Verified result / limitation |
|---|---|
| Expression | Built-in pedal with toe-operated on/off switch; external FP02M through CONTROL IN [M] |
| Knobs / footswitches / separate buttons | **5 / 6 / 0** on accessible panel: four front parameter knobs plus rear MASTER; four effect switches, PLAY MODE and TAP. Pedal on/off and power switches are additional, not counted twice [M,E] |
| Dimensions / weight | **418 W × 228 D × 65 H mm; 1.94 kg**. Maximum expression travel and cable clearance additional [M] |
| Screen | **4.3-inch TFT color touchscreen, 480×272** [P,M] |
| Simultaneous processing | **Up to nine effect spaces, DSP-limited**. Large effects occupy two spaces; send/return also uses a space. The Japanese page describes nine effects or seven plus an amp. Do not treat the English landing page's abbreviated seven-effect line as the complete architecture [M,J] |
| Categories / choices | Published effect list has **12 categories**: dynamics, filter, drive, amp, cabinet, modulation, SFX, delay, reverb, pedal, send/return, IR. Complete current category counts remain unverified; do not mix the 2021 list with later Guitar Lab additions without labelling dates [E,P] |
| Memory | **240 editable patches, 60 banks × four**, including **100 factory-supplied presets**, not 240+100 [P,M] |
| Acoustic / synth | **Aco.Sim electric-to-acoustic simulator verified** in DRIVE category. No dedicated synthesizer established in the inspected list; SFX/pitch processing alone is not enough to mark synth yes [E] |
| IR | **70 factory IRs plus 130 user locations (071–200)**. Import WAV, 44.1–192 kHz, 16/24/32-bit through SD/Guitar Lab workflow. Maximum sample-length limitation not independently established [M] |
| NAM / captures | Native NAM, converted NAM and amp-capture import **not established**. IR loading is a separate capability |
| Audio I/O | Mono 6.35 mm input; mono send/return loop; 3.5 mm stereo aux; two 6.35 mm main outputs. **LEFT/MONO doubles as stereo headphone output**; there is not a separate headphone jack. SEND socket is listed as TRS, but loop operation is described as mono [M] |
| Other ports | External control, USB **Micro-B**, SD/SDHC/SDXC, REMOTE for optional BTA-1, DC. No XLR microphone/phantom or physical DIN/TRS MIDI connection in complete manual inventory [M] |
| Power | **9 V, 500 mA, center-negative AD-16 supply**. **USB bus power explicitly unsupported**. Battery operation not specified; 500 mA is the adapter requirement, not measured draw [M] |
| Apps | **Guitar Lab Windows/macOS** full effect/patch management and editing. **Handy Guitar Lab iOS/iPadOS requires optional BTA-1**. Android/Linux full editor not established. Current support lists Guitar Lab7.3 and G6 firmware2.00 [M,D] |
| USB audio | **2-in/2-out, 44.1 kHz/32-bit**; Windows ASIO driver, Mac/iOS class support. Interface compatibility does not establish USB-powered operation [M] |
| Practice/live | **90-second mono or 45-second stereo looper without SD**, up to two hours with SD, 256 loop files; **68 rhythm patterns**, tuner, preselection, patch/stomp/looper modes [M,P] |
