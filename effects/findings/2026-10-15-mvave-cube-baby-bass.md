## Configuration software — directly manufacturer-confirmed

The [manufacturer download page][D] explicitly lists **Cube Baby Bass under CubeSuite for Windows and macOS**, connected over USB. Its mobile CubeSuite compatibility list does **not** name Cube Baby Bass. Android/iOS editing is therefore not established merely because a mobile application with the same name exists. The indexed manual describes both preset editing and cabinet IR import. A separate M-VAVE NAM-conversion utility does not establish NAM compatibility for this particular processor.
