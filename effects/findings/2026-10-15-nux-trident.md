# NUX TRIDENT NME-5

Reviewed **2026-10-15**. Guitar multi-effects; **large**, no built-in expression. First-pass record with explicit remaining gaps, not a claim of complete verification or live Shopee stock.

## Hardware and processing

| Required field | Evidence-backed result |
|---|---|
| Expression | No built-in pedal; one 6.35 mm external EXP input. External pedal is not included [M,P] |
| Rotary / footswitch / button counts | **19 / 10 / 4**: 18 front rotary controls plus rear MASTER VOL; ten footswitches; NR/AMP/CAB/EQ buttons. Encoder presses are not counted again. Five front three-way toggles, rear ground-lift and power switches are separate [M] |
| Dimensions / weight | **312 × 164 × 65 mm L×W×H; 1.65 kg**, V1 manual specifications. Large regardless of horizontal-axis naming. Pedalboard plugs need extra space [M] |
| Display | LCD; diagonal **unverified**. Manual depicts monochrome readouts, but an illustration does not establish physical panel color depth. Touchscreen specification **unverified**; knob navigation is not proof of no touch [M,P] |
| Architecture | **10 independently movable blocks:** NR, BOOST, FX, AMP, CAB, EQ, send/return, MOD, delay, reverb. Loop block is an external insert, not an extra internal sound algorithm [M] |
| Available choices | V1 overview: **27 amps; 7 boosts; 7 FX; 11 modulation; 3 delays; 4 reverbs**. Global product page states **27 factory cabinet IRs**. Detailed current-firmware subtotals for gate/EQ/FX and amp/cab lists remain unverified; the mirror's extracted appendix is inconsistent and is not used for an invented grand total [P,M] |
| Presets | **96 factory + 96 user**, accessed by toggling SELECT between factory and user modes; each has 32 banks × A/B/C. Confirmed visually on printed p.9. The overview's shorter “96 slots” wording must not erase the separately documented factory bank [M] |
| Synth / acoustic simulation | Dedicated synth and electric-to-acoustic simulator algorithms **not established** in inspected official material. A pitch bender, acoustic-named boost or bass-named amp alone is not such proof |
| IR import | **1024 samples**; one user-IR location associated with each patch, plus **32 additional custom IR slots**. Keep per-patch and library storage distinct; official Chinese page describes 96+32. Exact accepted file-format conversion rules remain unverified [P,M,C] |
| NAM / amp captures | Native NAM, converted NAM and user amp-capture import **not established** for TRIDENT. Other NUX models' NAM updates are not copied to this hardware |

## Connections, power and software

| Field | Result |
|---|---|
| Audio input/loop | One 6.35 mm instrument input, 3.5 mm aux, mono 6.35 mm send and return. Loop can be serial, parallel or send-only branch [P,M] |
| Outputs | Two unbalanced 6.35 mm main outputs, two balanced XLR DI outputs, dedicated 6.35 mm headphones. XLR outputs do not establish microphone input or phantom power [M] |
| Data/control | Two separate 3.5 mm MIDI IN and OUT sockets; USB-C; external EXP; DC input [P,M] |
| Power | **9 V center-negative**. Rear panel specifies **500 mA supply**; V1 specifications state **less than 330 mA draw**. These are different quantities, not a conflict. Internal battery and USB-powered operation remain unverified [P,M] |
| Configuration apps | **Trident Editor Windows/macOS**, full patch/parameter/routing/IR management; current official downloads pair firmware and editor **2.0.1**. Mobile/Linux full editors not established [P] |
| Recording | USB audio with dry recording and reamp; exact channel count unverified. Official device processing specification **48 kHz/32-bit** [P] |
| Practice/live | **30-second pre/post looper**, tuner, tap tempo, global output EQ and assignable external expression. An internal rhythm generator is not established [P,M] |
