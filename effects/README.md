## Size and expression categories

Use manufacturer unit dimensions, **W×D×H in millimetres**, never packaging dimensions.

| Bin | Width and depth test |
|---|---|
| Compact | Width ≤200 mm **and** depth ≤140 mm |
| Medium | Width ≤300 mm and depth ≤200 mm, but not compact |
| Large | Exceeds medium width or depth |
| Unknown | Width or depth unverified |

Do not rotate a unit to make it pass. Plugs, cable strain relief and expression-pedal movement need additional clearance. Distinguish **built-in expression**, **external expression only**, and **neither/unverified**; a socket is not an included pedal.

## Required comparison fields

Expression; rotary/footswitch/button counts; separate used/new **IDR** prices; simultaneous blocks and category choices; I/O; factory/user memory; synth/acoustic functions; dimensions/weight; power/battery/USB operation; IR/NAM/capture formats; editor platforms; **screen diagonal, monochrome/color and touch support**.

Additional fields include headphone/DI/phantom outputs, USB audio/reamp, MIDI, scenes, parallel routing, bypass/trails, looper, rhythms, firmware context and special pickup/cable needs. See [METHODOLOGY.md](METHODOLOGY.md).

`?` means **unverified**, not No. Color, display technology and touch are independent. Foreign quotes may remain provenance, but IDR conversion requires a sourced dated exchange rate and an **FX estimate** label. An asking price is not a completed sale; a converted international quote is not a local delivered price.
