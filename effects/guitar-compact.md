# Compact guitar / multi-instrument processors

[Home](README.md) · [Methodology](METHODOLOGY.md) · [Resume](RESUME.md) · [Larger processors](guitar-floorboards.md) · [Bass](bass.md) · [Vocals](vocal.md)

Research snapshot **2026-10-14**. All eight units satisfy the **200 mm width × 140 mm depth** filter using published dimensions. Height, plug clearance and expression-pedal movement still matter. Pocket Master is a handheld/desktop processor, not a conventional foot-operated pedal.

**Status: partial records.** The first display/Indonesian-price review is now saved for all eight models, with a separate findings commit for each. Five screen diagonals are established; three diagonals and explicit touch specifications remain unresolved. **All primary comparison price columns below now use IDR.** Missing local quotes remain `?`; old foreign quotes are preserved separately as provenance, not silently converted.

`?` means unverified, not No. `K/F/B` = rotary controls / main footswitches / separate push-buttons; expression toe switches are separate. A push-encoder is counted once. `P/U` = factory/user memory unless factory-filled total storage is explicitly stated. No model is certified fully researched.

### Firmware-sensitive notes

Sonicake's checked Matribox download section lists firmware **1.1.0** and desktop software **1.1.1** with NAM A2 support; its instructions require the older software for the firmware-update step. Pocket Master's page lists firmware **1.3.3**, Manager **1.5.2**, and SONICLINK **1.7.2**. Smart Box also lists iOS/Android SONICLINK **1.7.2**. Follow the matching manufacturer instructions. These are documented workflows, not compatibility tests of every NAM architecture or regional unit.

GP-150/180 documentation distinguishes operating, charging and fast-charging current. A USB socket or under-rated charger should not be assumed sufficient for every operation. Manufacturer battery runtimes are not independent measurements.

GP-100's checked firmware-1.8 manual has effect-total wording that differs from the current 140+ product-page summary. The total and rhythm-count conflicts remain unresolved. GP-5's July-2025 FAQ is retained with its date; planned features in that FAQ are not treated as definitive current firmware limitations.
