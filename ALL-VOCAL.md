The category includes different levels of vocal processing,not a claim that all15 offer harmony,automatic pitch correction,vocoding or guitar effects. Full evidence,firmware differences and unknowns remain in each linked record.

## Comparison rules and remaining work

Check microphone input type,phantom power,headphone/monitor outputs,guitar chord detection versus actual guitar processing,dual-output routing and mono/stereo distinctions before comparing vocal devices. Harmony,correction,vocoder,doubling and formant processing are separate functions,not interchangeable labels. A built-in formant pedal is not necessarily a general expression assignment.

Every record still requires its own screen,control,processing,preset,power,software and used/new IDR fields,with explicit unknowns where not established. A current seller title cannot resolve an old firmware conflict. Price observations and technical source dates remain separate; no new price or software verification is implied by this navigation view.

Legacy documents remain linked until their complete facts,source URLs and qualifications have been consolidated into root brand files and checked. No new per-progress or dated Markdown file is needed; root `research-state.json` holds the exact continuation. Never create or use GitHub Actions workflows. Unresolved owner identities and private receipt information are not published as confirmed ownership or public data.
