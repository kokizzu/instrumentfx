### Independent effects, expression and limitations

[Manufacturer User Guide1.0.0](https://cdn.inmusicbrands.com/sheeran/looper-x/Sheeran%20Looper%20X%20-%20User%20Guide%20-%20v1.0.0.pdf), printed24–29: FX racks target inputs/tracks. **Pre** processes incoming audio before recording; **Post** processes recorded audio. This establishes input multi-effects, not only loop transformations. Changing rack type requires removing and adding a rack. Factory/saved rack presets can be loaded and edited; exact user capacity remains unverified.

External expression accepts up to **four targets**, including FX parameters and track volume/pan, with configurable **LO/HI percentages**. This does not establish every-preset global master volume. Pedal resistance/wiring, toe support, position recall, bypass, headphone and tail/looper coverage remain unknown. Normal instrument inputs and dedicated headphones are documented above; next/previous FX-preset foot control is unverified.

Tuner defaults to muting inputs while recorded loops continue; inputs can be individually exempted. Saving WAV files on FAT32/exFAT has a4GB limit (~6h11m), or2GB on FAT16. These file limits qualify unlimited loop-length language. No recording, wiring, reset, firmware operation or local download performed.

### Firmware-qualified display, MIDI and preset-preview behavior

[Manufacturer release history1.0.2](https://cdn.inmusicbrands.com/sheeran/looper-x/Sheeran%20Looper%20X%20-%20Firmware%20Update%20v1.0.2.pdf), **October2024**, printed1,3–4. Updater minimum **Windows10 or macOS11,USB2.0** is a different scope from the FAQ’s audio requirements. Neither establishes current editor support.

**1.0.2** fixes display/green-LED mute-state mismatch, restores the last performance page when loading a loop, and corrects unreliable external-MIDI track selection. It also addresses external beat-clock alignment when replacing a Multi-mode loop and specified Band-mode stop/play glitches. These are documented corrections, not measured sync/latency guarantees or separate footswitch screens.

Earlier changes **since1.0.0** add navigation-wheel browsing of FX presets for preview while playing, rename Input Monitor to Live Signal, and fix pedal bank navigation with exactly six available loops. Wheel preview is not documented foot-controlled FX-preset down/up or automatic saving. Installed firmware, current behavior, global analog volume and output coverage remain unverified. No software downloaded or device operated.
