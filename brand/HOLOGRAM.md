## Chroma Console — partial discovery lead

Checked **2026-11-01**. Genuine multi-effects processor; **partial lead outside active model/brand counts**, not fully verified. No ownership established. This broader no-treadle discovery does not replace the individual-LCD research priority.

| Required field | Evidence / remaining qualification |
|---|---|
| Instrument scope | Manufacturer explicitly names guitar, bass, synths, vocals and drum machines [S]. Normal-pickup input is supported; microphone preamp/phantom capability is not established. |
| Built-in / external expression | No treadle in the documented control inventory. EXP accepts TRS, recommended potentiometer **>10 kΩ**; pinout, taper, maximum resistance and toe-switch support unverified [M,pp7,45]. |
| Across-preset volume | **PER PRESET expression mapping**: product explicitly saves/recalls mappings in user presets [P]. Manual permits one primary control: TILT/RATE/TIME/MIX/AMOUNT. **OUTPUT LEVEL is secondary**, with MIDI CC78; it is not a documented analog-EXP target [M,pp29,31,45–46]. Global input calibration does not establish global volume. Range, recall and bypass/tail/loop attenuation remain unknown. |
| Separate controls / displays | Text-derived **8 rotaries /2 footswitches /4 module buttons**; panel visual corroboration pending. Indicator lights provide navigation; no LCD or touchscreen documented in this inventory. No individual-foot-switch-LCD match established [M,pp7,36]. |
| Dimensions / mass | Manufacturer shop publishes **6.0×5.0×3.0 inches**, axes unlabeled: **152.4×127×76.2 mm** by exact conversion. Preferred W×D fit remains unverified until axes are confirmed. Mass unknown [D]. |
| Processing | **Four reorderable modules, five effects each:20 choices** [P]. This is four module positions, not20 simultaneous effects. No amp/cab modeling required for multi-effects eligibility. |
| Memory | **80 user presets** [P]. Factory-filled subset unknown; avoid adding protected factory slots. |
| Synth / acoustic / captures | HOWL is described as producing synth-like sounds [P]; this does not establish a dedicated synthesizer. Acoustic simulation, user IR, native/converted NAM and amp-capture support unverified. CAPTURE below is a phrase function, not amp profiling. |
| Audio / data inventory | Two quarter-inch inputs, two quarter-inch outputs, EXP, DIN MIDI IN/OUT, USB-C MIDI,9VDC. No dedicated phones socket listed; shared phones mode unknown. USB audio/editor support unverified [M,pp43–45]. |
| Power | **9VDC,center-negative,2.1mm,at least500mA supply**; not measured draw. Battery/USB-powered operation unverified [M,p44]. |
| Practice / stage | **CAPTURE up to30s**, pre/post routing; GESTURE records knob movement; Tap Tempo; true/buffered bypass and trails; selected-module bypass saved per preset [P]. Numeric tempo range, drums/scenes and loop retention still unverified. |
| Preset down / up | Browser: left/right footswitch moves one slot backward/forward; hold either to load. Audition behavior is global [M,pp34–36]. Separate from ordinary bypass/tap operation. |
| Software / firmware | Manufacturer lists **v1.04,May5,2025**, browser MIDI updater [F]. Desktop/mobile full-editor platforms unverified. No updater opened or device connected. |
