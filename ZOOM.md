## G11

Guitar and bass multi-effects; large; built-in expression. Specifications below use ZOOM's own V2 operation/effect documents and current support page. A first-pass record with unresolved fields is not fully verified.

| Required field | Verified specification / remaining uncertainty |
|---|---|
| Built-in / external expression | Built-in pedal with toe-operated effect on/off; one CONTROL IN for an external ZOOM FP02M. Separate rear power switch is not an expression control. [G11-M] |
| Physical controls | **11 footswitches**: five effect switches plus six SCROLL/PATCH/BANK navigation switches; **1 separate AMPLIFIER button**. Six amp rotary controls and a rear MASTER are explicit; complete rotary total across the five effect panels remains **unverified** pending successful visual inspection. Toe switch and rear power switch are separate. Marketing's five stomp switches must not erase the navigation switches. [G11-M, pp.11–14,23] |
| Main display | **5-inch, 800×480 TFT color touchscreen**. [G11-P, G11-M p.104] |
| Additional displays | **Six 128×32 dot-matrix LCDs**, one amp plus five effect displays. Their physical diagonals, explicit color mode and touch status are not established by the numerical specification; do not assign the main screen's five inches to them. [G11-M] |
| Dimensions / weight | **495 W ×253 D ×64 H mm;2.8 kg**. Large by the project's size bins. Pedal-up maximum height and cable clearance are additional/unverified. [G11-M p.104] |
| Simultaneous processing | Specification: **one amplifier plus nine effects**, DSP-limited. Operation pp.26,32 also describes up to ten freely combined effects; preserve that wording rather than assuming ten arbitrary high-load engines or unlimited duplicate amps. Overflow bypasses the excess effect. [G11-M] |
| Categories / choices | V2 effect list: Dynamics, Filter, Drive, Amp, Cabinet, Modulation, SFX, Delay, Reverb, Pedal, Send/Return and IR. Complete current per-category subtotals remain unverified. V2 added one guitar amp, nine bass amps and57 bass effects; additional OverDrive, BitCrush and DynaDelay were distributed in2025–2026. Do not sum the site's overlapping/launch-era totals as a current installed inventory. [G11-E,G11-F,G11-P] |
| Presets / user memory | **500 editable patch memories,125 banks×4** in V2. This replaces the earlier240 total. Factory-filled subset is not established;500 is not500 factory plus500 user. The V2 release added200 supplied patches. [G11-M pp.4,8,104; G11-F] |
| Synth | **Yes:** Z-Syn, BaStdSyn and BaSynTlk bass-synth algorithms in the V2 SFX list. Their documented bass purpose is retained, not asserted to be unrestricted polyphonic guitar synthesis. [G11-E p.32] |
| Electric-to-acoustic simulation | **Yes: Aco.Sim**, specifically described as converting an electric guitar's tone toward acoustic guitar, in the Drive category. Not merely an acoustic amp or body IR. [G11-E p.9] |
| User IR loading | **300 total locations:001–106 supplied;107–300 available for user assignment**, hence **194 remaining user locations** by arithmetic. WAV,44.1–192kHz,up to2048 samples. This supersedes launch-page70 supplied+130 user figures. The source's remaining-user-location description is not a claim all factory IR slots are freely overwriteable. [G11-M pp.3,86–88;G11-F] |
| NAM / amp captures | Native NAM, converted NAM and user amp-capture playback/creation are **not established** in the checked official materials. Cabinet IR import alone proves none of them. |
| Instrument / aux | One6.35mm mono input,500kΩ; one3.5mm stereo AUX IN,10kΩ. No microphone input/phantom power in the full published connector list. [G11-M p.104] |
| Outputs / loops | Two6.35mm mono main L/MONO,R outputs; dedicated6.35mm stereo headphones; two6.35mm SEND and two RETURN sockets, usable as two mono loops or stereo send/return processing. INST/LINE output-level selection. No XLR output in the published list. [G11-M pp.13–14,77–79,104] |
| MIDI / USB | Separate five-pin DIN MIDI IN/OUT; USB-C DEVICE for audio/Guitar Lab; USB-A HOST for IR/update flash drives; dedicated optional-BTA-1 REMOTE connector. [G11-M] |
| Power | **12V DC,center-positive,2000mA AD-19 supply**. Supply rating, not measured operating draw. **USB bus power explicitly unsupported**. Internal battery operation is not documented. [G11-M p.104] |
| Editor platforms | **Guitar Lab Windows/macOS**; support page lists7.3 for Windows8.1/10/11 and macOS10.13–26. **Handy Guitar Lab iOS/iPadOS requires optional BTA-1**. Android/Linux full editor not established. Driver support is a separate field. [G11-D,G11-I] |
| USB audio | **4-in/4-out,44.1kHz/32-bit USB interface**; two dry and two processed recording channels, reamp. Internal A/D and D/A24-bit,processing32-bit. Windows ASIO driver; Mac/iOS/iPadOS do not require a dedicated driver. [G11-M pp.89–91,104] |
| Practice / stage | **Five-minute stereo looper**, independent of the effect slots;68 rhythm patterns;looper PRE/POST placement and rhythm synchronization;autosave and preset preselection. Do not infer a measured preset-change latency or global spillover guarantee. [G11-M,G11-P] |
| Firmware / status | Support page lists **system2.10** at this check. V2 memory changes are explicitly documented. ZOOM's UK page labels G11 discontinued; this does not prove no Indonesian retailer has remaining stock. [G11-D,G11-F,G11-UK] |

## B2 FOUR — external expression-volume audit

**Checked 2026-10-18. Partial capability update, not complete consolidation of the existing bass profile.** [Cross-brand comparison](EXPRESSION-VOLUME.md).

| Capability | Finding |
|---|---|
| Built-in treadle | No; external FP02M input is documented. |
| Direct expression | Yes, separate EXPRESSION PEDAL jack; manufacturer identifies ZOOM FP02M. Other controllers' wiring/taper are unverified. |
| Assignment scope | **PER PATCH**: the manual instructs selecting a pedal effect inside the current patch memory. Only one pedal-category effect can be selected per patch. This is not a globally inserted volume effect. |
| Global master distinction | Master EQ and master volume retain their settings between patches, but the manual does not equate those panel controls with a global expression-volume assignment. |
| Correct footprint | **249 W ×146 D ×72 H mm; 906 g**. The earlier 184 ×145 mm comparison is not the B2 FOUR manufacturer's specification. Exceeds the 200 ×140 mm filter by 49 mm width and 6 mm depth, before plugs. |
| Headphones / normal pickup | Dedicated stereo mini PHONES output and normal instrument input; bass-oriented processing. |
| Verdict | Does not meet zero-per-preset configuration or strict chassis-size requirements. No new market-price claim is made. |

Source: [Official B2 FOUR HTML Operation Manual](https://zoomcorp.com/manuals/b2four-en/), sections **Using a connected expression pedal / Setting pedal effects**, **Signal flow**, **Functions of parts**, and **Specifications**. Original HTML text was read, including the explicit 249 W ×146 D dimensions. This is not a specification for G2 FOUR or another ZOOM model. Existing broader technical/price evidence and unresolved fields remain in the bass comparison pending lossless consolidation.
