# InstrumentFX project instructions

## Repository boundary

The working repository for this project is **kokizzu/instrumentfx**, default branch **main**. Before writing through GitHub or pushing with git, verify that exact owner/repository. **Do not commit instrument-effects research to kokizzu/edrums**: that repository is only a formatting reference for an independent drum comparison.

## Resume instead of restarting

Read `effects/RESUME.md`, `effects/research-state.json`, `effects/METHODOLOGY.md` and the relevant current comparison page before researching or editing. Preserve the saved inventory, source links, unresolved facts and next-model cursor. Check current file SHAs before updates; never reset or force-push to an old checkpoint.

## Required output

Research guitar, bass, vocal and specialist effects, organised by instrument/function, size and expression support. Include every required field in the checkpoint, especially **screen size, monochrome/color, touchscreen and separate used/new IDR prices**. Never infer specs or exchange rates. Keep unavailable values explicitly unknown; keep original foreign-price evidence separate from IDR comparison values.

## Incremental commits

Commit each completed category/model batch separately with a descriptive scope. Save verified partial work rather than claiming an entire model is complete while required fields are missing. Update the checkpoint and machine-readable cursor after each committed batch. Verify saved files and links before reporting completion. Repository relocation does not complete pending IDR or screen research.
