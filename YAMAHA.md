Partial manufacturer-backed records. Unknown is not No.

## SPX900

Rack multi-effects; checked 2026-10-17. Guitar/vocal processing requires suitable preamp/mixer routing, not a direct microphone-input claim. Bass suitability remains unclassified.

| Field | Evidence / qualification |
|---|---|
| Instrument scope | Guitar distortion and vocal reverb applications documented; line-level routing [S9-M, S9-A] |
| Expression | No built-in pedal/toe; two front EXT CTRL/FOOT VOL sockets accept FC7 parameter controllers [S9-M pp.4,8] |
| Knobs / footswitches / buttons | 1 Input rotary; 0 built-in footswitches; 15 buttons derived from named keys, counting parameter and memory arrows separately; power separate [S9-M pp.3–4] |
| Display | 16×2 character LCD, two-digit memory LED, seven-segment input meter; diagonal/color/touch unverified [S9-M p.4] |
| Processing / categories | Up to five simultaneous effects claimed by archive. Programs 38–47 combine compression, distortion, EQ/filter and other effects; configuration-specific, not arbitrary blocks [S9-A; S9-M p.23] |
| Preset memory | 50 ROM + 49 user = 99; factory-filled user subset unverified [S9-M p.6] |
| Synth / acoustic | Pitch and Freeze sampling documented; dedicated synth/acoustic simulator unverified [S9-M] |
| IR / NAM / captures | User IR, native/converted NAM and measured capture support unverified |
| Audio / control ports | Mono TS input, stereo TS outputs; MIDI IN and switchable OUT/THRU; bypass, memory and trigger footswitch sockets; RCX1 remote. Digital-port identity remains unresolved [S9-M p.5] |
| Analog levels / conversion | Switchable −20/+4 dBm; 16-bit conversion. Manual impedance notation conflicts internally with mono-input inventory; do not normalize to archive’s 50-ohm transcription [S9-M Add-39; S9-A] |
| Power / battery / USB | US/Canada 120 V 60 Hz; general 220–240 V 50/60 Hz; 20 W. DC polarity not applicable to listed mains versions. Battery operation/USB power unverified [S9-M Add-39] |
| Dimensions / weight | W480 × H45.2 × D319 mm; 4.4 kg [S9-M Add-39]. Archive swaps depth/height labels; preserve manual order |
| Editor / software | Current editor platforms unverified; MIDI dumps do not establish an editor or USB audio |
| Looper / drums / live | Freeze sampling differs from a performance looper. Looper, drums, scenes and spillover unverified |
