### Expression-volume and navigation screen

Manufacturer-authored **firmware2.3.0+ User Manual**, nineteen-page reproduction, pp2–5/11: text inventory derives eight push-rotary controls and two footswitches; no built-in treadle, separate-button count pending visual corroboration. Thirty-two presets; factory-filled/user split unverified. Both footswitches together advance banks; independent onboard down/up unverified. [M]

EXP requires **10–25 kΩ, wiper-to-tip**; ring-wiper pedals are explicitly unsupported. Up to six primary algorithm parameters can be mapped; heel/toe values autosave in the current preset. Master Volume is instead a per-preset **−3…+3 dB** control. No global analog master-volume assignment established; current2.5.1 applicability, position recall, bypass/headphone/tail/loop attenuation remain unknown. All-preset unmapping is not global volume mapping. Headphones, full display specifications, synth/acoustic distinctions, IR/NAM/capture and looper/drums remain unverified. [M]
