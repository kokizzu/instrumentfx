## RP55

**Capability-focused partial profile, checked 2026-10-18.** Legacy processor screened as a possible inexpensive no-treadle alternative; not yet admitted into the older catalogue totals. This is not a specification for RP50, RP70, RP150, RP155 or other similarly named models.

| Field | Manufacturer evidence / qualification |
|---|---|
| Built-in / external expression | No built-in treadle. CONTROL IN accepts a passive mono volume pedal used as a controller, or a **TS expression pedal**. **TRS expression pedals are explicitly unsupported** in this manual. An unspecified M-VAVE TRS controller is therefore not a verified direct match. |
| Volume behavior | **CONDITIONAL automatic volume**, not a dedicated always-volume global assignment. When both Wah and Whammy are disabled, the external pedal controls volume. Enabling either changes the pedal's function to the effect. Thus a switch to another preset can stop it behaving as a volume pedal. |
| Strict requirement | **Does not pass** the requested always-volume-across-arbitrary-presets filter. Global Cabinet Modeling is a different feature and does not make pedal volume global. |
| Size / mass | Manual: **6.5 inches W × 5.65 inches L × 2.5 inches H**, equivalent to **165.1 W × 143.51 D × 63.5 H mm** using exactly 25.4 mm/inch. Depth is **3.51 mm over** the 140 mm chassis limit before plugs. Manual unit weight 1 lb; with supply 2 lb. |
| Audio ports | 1/4-inch instrument input; 1/4-inch stereo TRS main output also explicitly usable for headphones. CONTROL IN and DC input are separate. No divided pickup required. |
| Memory / processing | **40 user + 40 factory presets; up to eight simultaneous effects**. Advertised library includes pickup simulation, wah, compression, 11 amp models, acoustic simulation, EQ, gate, cabinet modeling, modulation/pitch, delay and reverb. Complete independent per-category counts remain to audit. |
| Practice / power | 30 drum patterns; 6 AA or optional 9 V DC supply. Manual supply table shows center-negative PS200R 300 mA or PS0913DC 1300 mA; these are alternative supply ratings, not measured draw. Published maximum consumption 5 W. |
| Remaining profile fields | Complete physical control/display classification, current legacy-support status, qualified used/new IDR, exact bundles/stock and any firmware changes. USB/editor/IR/NAM features are not inferred from later DigiTech models. |

The automatic Wah/Whammy override and TS-only warning are explicit manufacturer text. No physical pedal test is claimed.
